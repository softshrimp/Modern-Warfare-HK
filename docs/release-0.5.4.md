# 0.5.4：Gemini文本整合版

本版接收Gemini的0.5.2／0.5.3文本及另存的335條覆核記錄，再修正封裝遺漏及整合時發現的問題。翻譯資料已更新，執行DLL、來源查找表及載入器修改方式維持原版本。

## 收錄內容

- 累計15,639條完整字串規則及178條選單優先規則。
- 補回335條先前已存在於覆核檔、卻未寫入Gemini封裝的字串。原程式只更新既有鍵，沒有加入新鍵；本版逐一核對原始中文、英文參照及身份後補入。
- 相對公開版0.5.1，更新285條既有譯文。
- 對新收文字再處理殘留的台灣用語、粗口、人物指代及動作意思，並保留句中句號。
- 依使用者既定要求，保留兩處被新版建議改姓的韓國漢字稱呼，不改動姓名原寫法。
- 修正全域「著／着」替換波及正常詞語「顯著」的問題。
- 新安裝程式移除先前只針對個別電腦的效能問題提示。

## 覆蓋及驗證界限

全部已收到的Gemini文字均已納入整合，335條漏收規則已補齊。這不代表所有場景的語義疑問都已解決：原有23項語境／來源衝突，以及一項同一中文兼用於對白和音效描述的情況，共24項仍保留追查記錄。沒有單憑輸入檔的「三重通過」標籤宣稱全故事已完全認證。

本版檢查原始身份、控制標記、數字、韓國漢字姓名、句中句號、原生替換輸出及隔離安裝／還原。呼號一處由2-4改為2-5，按相應原生英文處理，另保留其來源矛盾的語境記錄。遊戲畫面由使用者自行核對。

安裝新版前，請完全退出遊戲，先還原舊補丁，再安裝0.5.4。
