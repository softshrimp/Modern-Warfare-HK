# 翻譯包統計方法

統計單位為完整字串表中的不同原文字串。每條規則保留遊戲原有繁中及本翻譯包文字，供逐條比對；同一句在遊戲中出現多次，仍按一個原文鍵計算。178條選單優先規則另走選單查找路徑，總數採用完整字串表的15,639條。

## 改動與保留

每條字串歸入以下一類，三類合計等於完整字串總數：

| 分類 | 計數方式 |
| --- | --- |
| 完全保留 | 原文與修訂文字逐字相同，包括標點、空白及遊戲控制碼。 |
| 只改標點或空白 | 文字有改動，但移除Unicode標點類別P、分隔符類別Z及空白後，兩者相同。 |
| 字句／字形等內容有改動 | 其餘改動，包括用字、字形、語義及其他內容差異。 |

「有改動」為後兩類之和。分類時保留字母、數字、符號及遊戲控制碼作比對。

## 英中錯譯例證

按[英中語義錯譯資料檔](semantic-corrections-0.5.15.json)中逐項列出英文、原譯、修訂及原因的100條不同原文字串計數。重算時，程式會逐條核對原文鍵及目前實際發佈文字。

此數值的統計範圍為已公開列證的英中錯譯個案；改動與保留則涵蓋完整字串表。

## 台繁轉港繁

使用[35對詞字對照表](../data/statistics-lexicon.json)核對港式詞彙、字形及寫法。每對詞字符合以下兩項條件，即命中該條字串：

1. 原有詞字在修訂文字中出現得較少。
2. 對應港式詞字在修訂文字中出現得較多。

例如「飛彈」減少且「導彈」增加，該字串便計入這對詞彙。詞字在同一字串中重複出現，仍只計一條。各詞字長條獨立計數，總數則合併所有命中字串後去重。字形對照按實際減少及增加計算，例如「著」與「着」各自保留的用法不會因單純出現而被計入。

詞彙與字形可出現在同一條字串；英中語義修正亦可與港式用語調整重疊。台繁轉港繁數值的統計範圍為這份公開對照表命中的修訂。

## 數據與重算

- [統計摘要JSON](statistics-0.5.15.json)：輸入檔案校驗碼、分類數量及每對詞字的字串數。
- [逐條分類CSV](statistics-0.5.15.csv)：15,639個原文鍵的改動分類、英中錯譯例證編號及詞字對照編號。
- [圖表產生程式](../tools/build_readme_stats.py)：直接讀取發佈字串表，核對原文雜湊、資料筆數及例證文字，再重建JSON、CSV與兩張圖表。

於儲存庫根目錄執行：

```sh
python -m pip install matplotlib
python tools/build_readme_stats.py
```

中文字體使用Microsoft JhengHei、Noto Sans CJK或PingFang。程式按`data/manifest.json`的版本號產生對應檔案。
