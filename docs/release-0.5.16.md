## 整合處理

李承鎬的說話者標籤採用姓名，對白稱謂使用「領袖」；原有韓國漢字姓名逐條保留。Simon的7條修訂保留「西蒙」，以維持較貼近英文首音的寫法。What the fuck一句保留用戶指定的「搞甚麼飛機」，只更新說話者拉斯威爾的譯名。

累積15,639條完整字串及178條選單優先規則。先前補回的335條字串、執行DLL、來源查找表及選單優先規則逐位元組保留。內文句號、數字、換行及控制碼按本版改動逐條核對；兩條任務提示中的人名顯示文字隨譯名更新，控制結構維持一致。
